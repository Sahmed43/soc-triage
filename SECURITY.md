# Security policy for this training project

This is an offline educational lab, not a supported production SOC platform. Do not process classified, proprietary, regulated, customer, or unsanitized operational data in a publicly shared repository.

The tool intentionally does **not** perform live scanning, containment, credential collection, execution of event commands, or connection to a SIEM tenant.

Do not commit `.env` files, API keys, credentials, network inventory, production exports, or SQLite casebooks to public GitHub. Review JSON/Markdown report contents before sharing.

To report a security issue in a fork or adaptation, use the repository's private vulnerability-reporting mechanism rather than exposing sensitive data in a public issue.
